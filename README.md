# Studi Kasus: Implementation of Human-Computer Interaction & Data Visualization

Repositori ini berisi implementasi sederhana untuk studi kasus dari kuliah umum *Informatics Practitioner Lecture Series* bertajuk **"Make Sense of Data with Analytics and AI"** yang dibawakan oleh **Bapak Arafat Febriandirza**.

## 📌 Topik Pembahasan
1. **Human-Computer Interaction (HCI):** Menampilkan ringkasan informasi utama (Overview) di posisi paling atas agar memudahkan fokus mata dan daya ingat pengguna.
2. **Data Visualization:** Menggunakan jenis grafik garis yang tepat untuk melihat tren naik-turun data penjualan dari waktu ke waktu.
3. **Analytics & AI:** Memberikan fitur pemrosesan data interaktif dan ringkasan nilai metrik secara otomatis.

## 🛠️ Teknologi yang Digunakan
* **Python**
* **Streamlit** (untuk visualisasi dan pembuatan antarmuka web)
* **Pandas** (untuk pemrosesan data)
